# 우리 가족 일정표 📅

설치 없이 브라우저에서 바로 쓰는 가족 일정 관리 웹앱입니다. 단일 HTML 파일이라 파일 하나만 열면 동작합니다.

## 사용법

`index.html` 파일을 더블클릭하거나 브라우저로 열면 끝입니다. 휴대폰에서도 그대로 열립니다.

## 주요 기능

- **가족 구성원별 색상 구분** — 상단 칩을 눌러 특정 구성원 일정만 골라 볼 수 있어요.
- **월간 / 주간 보기 전환** — 오른쪽 상단 토글로 전환합니다.
- **일정 추가·수정·삭제** — 날짜 칸을 누르거나 우측 하단 `＋` 버튼으로 추가합니다.
- **반복 일정** — 매일 / 매주 / 격주 / 매월 반복을 지원합니다 (예: 학원, 정기 모임).
- **하루 종일 일정** — 시간 없는 종일 일정도 등록할 수 있어요.
- **메모** — 장소, 준비물 등을 함께 적어둘 수 있습니다.
- **가족 구성원 관리** — 이름과 색상을 자유롭게 추가·수정·삭제합니다.
- **백업 / 복원** — ⬇️ 로 JSON 백업을 내려받고, ⬆️ 로 다른 기기에서 불러옵니다.
- **다크 모드** — 기기 설정을 자동으로 따라갑니다.

## 데이터 저장

모든 데이터는 **해당 브라우저의 localStorage**에만 저장됩니다. 서버로 전송되지 않으며,
다른 기기·브라우저로 옮기려면 백업 내보내기(⬇️) 후 가져오기(⬆️)를 이용하세요.

## 기술

순수 HTML/CSS/JavaScript 단일 파일. 외부 라이브러리·빌드 도구·인터넷 연결이 필요 없습니다.
